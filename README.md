# benzin-crawl

benzin.mn-ээс ШТС-ын системийн мэдээг татаж хоёр жагсаалт гаргана:

1. **Орлого буусан ШТС** — сүүлд орлого буусан цагаар нь (шинэ нь дээрээ).
2. **92 бензин хэвийн өгч байгаа ШТС** — түгээлт явж байгаа, Аи-92 (сонголтоор Евро-92)
   нь «Хэвийн» төлөвтэй (дуусаагүй, дундраагүй). ШТС мэдээгээ шинэчилсэн цагаар нь.

Анхдагчаар зөвхөн Улаанбаатар хот доторх ШТС (`crawler.CITY_BBOX` координатын хүрээ).
Газрын зураг дээр хоёр жагсаалтын ШТС дугаартайгаа гарна. ШТС дээр дарахад камер,
түлш тус бүрийн төлөв, үнэ, савны түвшин, орлогын түүх, хүмүүсийн мэдээ харагдана.

## Ажиллуулах

Python 3.9+ л хэрэгтэй, нэмэлт сан шаардлагагүй.

`index.html`-г файлаар нь шууд нээж болохгүй — сервер ажиллуулаад хаягаар нь нээнэ.

```sh
python3 server.py          # http://127.0.0.1:8000 → «Жагсаалт гаргах» товч
python3 crawler.py         # UI-гүйгээр терминал дээр хэвлэнэ
```

## Өгөгдлийн эх үүсвэр

- `https://benzin.mn/api/gov/feed` — ШТС-ын системтэй холбогдсон станцуудын төлөв, `refills`
  (савны түвшин өссөн хэмжилт = орлого буусан), түлш тус бүрийн `state`
  (`normal` / `medium` / `low` / `stopped` / `stale`).
- `https://benzin.mn/api/stations/<id>` — хаяг, компани, камер (жагсаалтад 6 цаг cache),
  станц дээр дарахад 30 секунд cache-тэй шинээр татна.
- Камер: `stream.ubtraffic.mn` HLS. Safari/Chrome шууд тоглуулна, бусад нь `/cam/` proxy + hls.js.

Feed-ийг 30 секунд cache хийдэг (benzin.mn өөрөө ч мөн адил).
